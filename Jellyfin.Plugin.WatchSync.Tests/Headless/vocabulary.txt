# The vocabulary the headless guard refuses in the tracked test sources.
#
# Four fields per entry, separated by " :: ":
#   id :: regular expression :: what a test matching it would need :: what to use instead
#
# Blank lines and lines beginning with # are ignored.
#
# This file is data rather than source on purpose. A scanner that carried these
# literals in a .cs file would match itself, and the exclusion that fixed that would
# be a hole in the middle of the guard.
