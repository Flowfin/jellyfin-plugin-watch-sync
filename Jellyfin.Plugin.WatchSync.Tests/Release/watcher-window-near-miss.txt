A slice of the watcher's sweep as it first shipped. A red run is reported only while it is
recent, so a scan that runs weekly is filed on the day it goes red and closed again by the
next day's tick, saying nothing is red any more, while the failure stands for another six
days. The narrower the schedule of the thing being watched, the longer the silence.

          WINDOW_HOURS: "24"
        run: |
          cutoff=$(date -u -d "-${WINDOW_HOURS} hours" +%Y-%m-%dT%H:%M:%SZ)

          jq -r --arg self "$SELF" --arg cutoff "$cutoff" --arg branch "$branch" --rawfile tags tags.txt '
            .[]
            | select(.workflowName != $self)
            | select(.updatedAt >= $cutoff)
            | select(.event != "pull_request" and .event != "pull_request_target")
            | select((.conclusion // "") as $c
                     | $c != "success" and $c != "skipped" and $c != "cancelled" and $c != "")
            | [.url, .conclusion, .event, .workflowName] | @tsv
          ' runs.json > red.tsv
