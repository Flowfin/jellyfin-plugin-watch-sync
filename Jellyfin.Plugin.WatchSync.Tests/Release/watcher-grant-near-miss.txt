A slice of the watcher's job after the grant somebody adds to make a step work. It is one
line, the job still files its issue, and the token that reads a failed run's log can now
write the tree.

permissions: {}

jobs:
  sweep:
    name: Report any run on the default branch or on a tag that concluded other than success
    runs-on: ubuntu-latest
    timeout-minutes: 5
    permissions:
      actions: read # the run list and the failed step's log
      contents: write
      issues: write # the one tracking issue, and the label it is found by
    steps:
      - name: Sweep the runs and file, update or close the alert issue
