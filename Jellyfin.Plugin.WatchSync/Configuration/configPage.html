Watch Sync moves watch history and playback positions between servers that are already paired. Pairing, trust and the mapping between users belong to the Server Pairing plugin and are not part of this one, so without that plugin installed and enabled this plugin syncs nothing.

This page does not yet read whether the Server Pairing plugin is present, enabled, or of a version this plugin was built against, so the settings below taking a value is not a statement that everything is in order.

Every setting on this page is server-wide. A setting belonging to one pairing is deliberately not here, because this document is one an operator copies between servers and a per-pairing value copied that way points at a peer that is not there. The action at the bottom of the page is about one person and is not a setting: nothing about it is stored in this document and nothing about it is copied anywhere.

What each setting below does, what happens at either end of its range, where the value is stored and whether it survives a copy of this configuration to another server is in the settings reference. What this plugin moves between two servers, what it keeps about a person and for how long is in the note on what moves and on whose authority. Neither is repeated here, because a second copy of a range drifts from the one that is enforced.

What is held about one person

Somebody who asks what this plugin holds about them, or asks for it to go, is answered here rather than by an administrator opening files. Both actions are about the person whose identifier is in the field below, and both need an administrator account.

Removing these records does not remove what that person watched. Their watch history belongs to the server and stays exactly where it is. What goes is this plugin's own record of what it agreed with a peer, what it wrote, what it could not match and which conflicts it resolved.

The identifier this server gives the account, which is in the address bar of that user's page in the dashboard. It is not a setting and nothing here is saved with the settings above.
