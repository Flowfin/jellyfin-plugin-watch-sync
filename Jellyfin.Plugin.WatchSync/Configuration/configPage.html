Watch Sync moves watch history and playback positions between servers that are already paired. Pairing, trust and the mapping between users belong to the Server Pairing plugin and are not part of this one, so without that plugin installed and enabled this plugin syncs nothing.

This page does not yet read whether the Server Pairing plugin is present, enabled, or of a version this plugin was built against, so the settings below taking a value is not a statement that everything is in order.

Everything on this page is server-wide. Anything belonging to one pairing or to one person is deliberately not here, because this document is one an operator copies between servers and a per-pairing value copied that way points at a peer that is not there.

What each setting below does, what happens at either end of its range, where the value is stored and whether it survives a copy of this configuration to another server is in the settings reference. What this plugin moves between two servers, what it keeps about a person and for how long is in the note on what moves and on whose authority. Neither is repeated here, because a second copy of a range drifts from the one that is enforced.
